# Fonts

Self-hosted WOFF2 files for the app.

## Families

- Amiri Quran, weight 400, Arabic subset
- Amiri, weights 400 and 700, Arabic and Latin subsets
- Tajawal, weights 400 and 700, Arabic and Latin subsets

These are the Google Fonts subsets, downloaded from `fonts.gstatic.com`.
The full font families are available from the upstream projects:

- Amiri: https://github.com/aliftype/amiri
- Tajawal: https://github.com/google/fonts/tree/main/ofl/tajawal
